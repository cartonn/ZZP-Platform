# V5 platform integration

The owner asked to carry the Handslag V5 design into the platform: responsive navigation, depth, layered surfaces, shadows and feedback for pointer, touch and keyboard. The public homepage is reviewed separately in PR1478; this branch integrates that exact landing source and retains the protected platform changes in PR1474.

The platform adopts Open Sans, the Handslag palette, shared surface and control styles, responsive dashboard spacing and mobile navigation. Black logo hands indicate work awaiting approval; orange seals indicate effective approved status. Disputed collaborations suppress approval seals. The server remains the status authority, and role/access/payment rules are unchanged. Keyboard focus stays visible over the elevated active navigation item, and reduced-motion preferences are respected.

The first complete combined landing/platform review hit its time limit after 35 successful API requests without a final report. This did not approve the change. The public landing was split out, its photo-source and no-script FAQ findings fixed, and those fixes integrated here. The photo now uses its documented original Unsplash object and exact rendition; see `src/components/landing/ASSETS.md`. Open Sans provenance remains alongside the local font.

Before the split, local lint, TypeScript, all 8,692 unit tests (2 existing skips), formatting and five landing journeys passed, with desktop and 390 × 844 visual checks. The final integrated tree also passes lint, TypeScript, the same 8,692 tests with two existing skips, production build and full formatting. All six current GitHub gates, including a complete independent review against the current main/head pair, remain required before merge. Local readiness or an incomplete review never counts as merge approval.
