# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in the ZZP Platform, please report it
responsibly. **Do not open a public issue.**

**Contact:** Email [cartonn78@gmail.com](mailto:cartonn78@gmail.com) with subject
line `[SECURITY] ZZP Platform`.

**What to include:**

- Description of the vulnerability
- Steps to reproduce
- Impact assessment
- Suggested fix (if any)

**Response time:** We aim to acknowledge reports within 72 hours and provide a
fix or mitigation plan within 14 days.

## Scope

This policy covers the ZZP Platform application, including:

- The Next.js web application and its API routes
- Authentication and authorization flows
- Document storage and access control
- Credential verification workflows

## Responsible Disclosure

- Do not publicly disclose the vulnerability until it has been fixed.
- Do not access or modify other users' data beyond what is necessary to
  demonstrate the vulnerability.
- Do not perform destructive actions or denial-of-service attacks.
